# KSU Tech Certificates

Certificate generator for the KSU Marketing Club Technical Department. Members type their first name, last name and role in a terminal, and their animated certificate builds itself. The finished certificate can be downloaded as a PDF.

- Members receive **TECH LEGEND**, leads receive **TECH MASTERMIND**.
- Names are never stored or sent anywhere; everything runs in the visitor's browser.
